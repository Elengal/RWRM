# RimWorldRu — Полный русификатор RimWorld

Полный перевод RimWorld и всех официальных DLC на русский язык с набором дополнительных улучшений через Harmony-мод RuMod.

## Переводимые DLC

| DLC | Файлов перевода |
|-----|-----------------|
| Core | 722 |
| Ideology | 297 |
| Biotech | 225 |
| Odyssey | 201 |
| Anomaly | 181 |
| Royalty | 154 |
| DevMode | 36 |
| RimHUD (совместимость) | 7 |

**Итого: 1823 файла перевода.** Перевод нужных DLC подхватывается автоматически — достаточно, чтобы DLC был активирован в игре.

## Возможности RuMod

RuMod — это встроенный C#-мод (Harmony), который идёт вместе с переводом и расширяет игру:

### Перевод

- **Русские имена пешек** — имена, фамилии и клички берутся из словников мода. Банк имён игры при этом не переписывается: мод перехватывает выдачу, поэтому настройку можно выключить и получить обратно ванильные имена сразу, без перезапуска. Русские имена, добавленные другими модами, сохраняются.
- **Фамилии по полу** — игра хранит фамилии одним списком без рода. Мод выдаёт мужскую или женскую форму по полу пешки: Давыдов и Давыдова.
- **Имена по расам** — своего генератора имён у гемофагов, ангелов, гусар, инжей и неандертальцев в игре нет, все они получают обычные человеческие имена. Мод раздаёт им собственные: гемофагам румыно-балканские, ангелам греко-римские (их выводили «под моду классической Новаромы»), гусарам воинские, инжам технические, неандертальцам гортанные.
- **Клички по нраву** — кличка выбирается по тому, к кому пешка принадлежит: пирату жёсткая, племени звериная, торговцу промысловая, поселенцу насмешливая. Ласковый регистр у разбойников не убран нарочно — кличка чаще даётся по контрасту, чем по сходству, и головорез по кличке Добряк выглядит достовернее ровной раскладки.
- **Клички по контрасту** — редкие прозвища, которые подбираются уже по готовой пешке: толстяка зовут Пёрышком, здоровяка Малышом, косого стрелка Ворошиловым, дурака Профессором. Всего 25 признаков — телосложение, черты, провальные навыки, увечья.
- **Имена спонсоров Ludeon** — 25% пешек и все лидеры фракций получают вшитые в игру имена людей, поддержавших разработку, плюс половина остальных — только имя. По умолчанию мод заменяет их русскими, но это отдельная настройка: имена спонсоров можно вернуть. Имена из списка «Предпочитаемые имена» не трогаются никогда.
- **Склонение возраста** — патч для RimHUD: корректное отображение «год/года/лет» в зависимости от числа.
- **Фамилия в семье** — ребёнок получает фамилию родителя в правильной форме. Перехвачены все пути появления младенца: обычные роды, роды как ритуал, ростовой чан и отладочные команды.
- **Перевод режима разработчика** — подписи в Dev-меню собираются игрой прямо из дефов, ни `Keyed`, ни `DefInjected` туда не ведут. Мод подменяет их на лету: часть берёт из своего словаря, остальное подставляет из уже готового перевода игры.

Фамилии сцеплены построчно: 676 пар, мужская форма и женская на одной строке друг с другом. Имя и фамилия дают **206 тысяч** сочетаний, так что в долгой игре панель колонистов не повторяется.

Те же 525 кличек дополнительно разложены по шести регистрам — жёсткие, звериные, промысловые, насмешливые, ласковые, скрытные — и лежат отдельными файлами: по ним мод и выбирает, кому какую дать. Сверх них 86 пар по контрасту на 25 признаков.

Помимо имён пешек в моде ещё 2807 строк — клички животных, названия поселений, планет, торговых компаний и природных объектов.

Имена набраны нарочно широкого регистра: святцы (Аввакум, Евпраксия), крестьянские обиходные (Фрол, Матрёна), славянские дохристианские (Ратибор, Рогнеда), советские (Владлен, Октябрина) и редкие современные. Фамилии — от ремёсел (Кожемякин, Скорняков), семинарские (Преображенский, Добронравов), дворянские (Волконский, Трубецкой), северные и сибирские (Устюжанин, Тобольцев) и тридцать несклоняемых (Черных, Коваль, Шевченко).

Словарь режима разработчика — 11 672 строки в 58 файлах.

### Геймплей

- **Снятие лимита фракций** — убирает ограничение на 12 фракций при создании мира. Можно добавить сколько угодно фракций.

### Визуальные улучшения

- **Фон главного меню** — выбор кастомного фона для главного меню (несколько вариантов или случайный).
- **Прозрачность панелей** — настройка прозрачности для панели переводчика, панели DLC и окна Debug log (10%–50%).
- **Перетаскиваемое окно переводчика** — можно двигать панель перевода на главном экране, позиция сохраняется.
- **Визуальные правки Debug log** — полупрозрачный фон, подстройка ширины под русские подписи.
- **Всплывающие подсказки в Dev-меню** — при наведении на пункт показывается полный текст команды.

### Для разработчиков

- **Совместимость с другими модами** — RuMod автоматически отключает конфликтующие визуальные патчи.

## Установка

### Через Steam Workshop

Самый простой способ — подписаться на мод в Steam Workshop. Перевод активируется автоматически.

### Вручную

1. Скачайте последнюю версию из [Releases](../../releases)
2. Распакуйте папку `RimWorldRu` в папку `Mods` внутри каталога, куда установлена игра:
   - **Steam:** `...\steamapps\common\RimWorld\Mods\`
   - **Отдельная установка:** папка `Mods` рядом с исполняемым файлом игры

   Сохранения и настройки лежат в другом месте — `AppData\LocalLow\Ludeon Studios\`, — но модам там не место, игра их оттуда не читает.
3. Запустите RimWorld, в мод-меню активируйте **RimWorldRu**
4. Мод должен загружаться **перед** Core (порядок определяется автоматически)

## Настройки

Все настройки доступны в меню мода: **Настройки → RimWorld RU**.

| Настройка | По умолчанию | Описание |
|-----------|-------------|----------|
| Фон главного меню | Случайно | Выбор фона: выкл / конкретный / случайно |
| Русские имена пешек | Вкл | Имена, фамилии, клички, имена рас и клички по нраву. Отключите при конфликтах |
| Оставить имена спонсоров Ludeon | Выкл | Вернуть вшитые в игру имена спонсоров вместо русских |
| Снять лимит фракций | Вкл | Без ограничений на число фракций при создании мира |
| Перетаскиваемое окно переводчика | Выкл | Позволяет двигать панель перевода |
| Подсказки Dev-меню | Вкл | Всплывающие подсказки при наведении |
| Прозрачность панелей | 25% | Для панели переводчика, DLC, Debug log |
| Визуальные правки Debug log | Вкл | Полупрозрачный фон, подстройка ширины |

Конфиг сохраняется в: `Config\RimWorldRu\Config.xml`

## Структура проекта

```
RimWorldRu/
  1.6/
    Core/           — перевод базовой игры
    Royalty/        — перевод Royalty DLC
    Ideology/       — перевод Ideology DLC
    Biotech/        — перевод Biotech DLC, имядатели рас
    Anomaly/        — перевод Anomaly DLC
    Odyssey/        — перевод Odyssey DLC
    DevMod/         — перевод DevMode
    RimHUD/         — совместимость с RimHUD
    Assemblies/     — скомпилированный RuMod.dll
    Textures/       — текстуры (фоны меню и пр.)
  About/            — метаданные мода (About.xml, иконка)
  LoadFolders.xml   — автозагрузка по DLC

RuMod_Source/       — исходный код RuMod (C# / Harmony)
  Main.cs           — точка входа мода
  ModSettings.cs    — все настройки
  Patches/
    Names/          — система русских имён, клички, имядатели рас
    Game/           — игровые патчи (фракции, меню, возраст)
    Debug/          — улучшения DevMode
    UI/             — визуальные патчи интерфейса
    RimHUD/         — совместимость с RimHUD
  Utils/            — утилиты (логгирование, переводчик)
```
